## UX設計の指針

### 落ち着くことが最優先
ユーザーの1日はすでに育児・仕事・家事で埋まっている。開くと肩の力が抜ける場所にする。

- **何もしなくても草は生える**。開かなかった日も、記録のない日も、空白にならない
- **量を測らない、比べない**。どの日の花も同じ大きさ
- **追い立てない**。催促の通知、「まだ蒔いていない」リマインダー、連続記録を迫る表示は置かない
- 蒔き残したタネはトゥーリが蒔いておく。やり残しが残らない

### スキマ時間に開ける軽量設計
- **起動から1秒以内に庭が見える**
- スクロール不要のメイン画面（縦で30日が一画面に収まる）
- 片手の親指だけで完結する

### 開く理由
記録するためではなく、**草むらとあの子たちを眺めに行く**。記録はそのついでに、気持ちよくできる。

## 中心の体験

### 1. 開く
月の画面が出る。草むらにユジュとトゥーリがいる。トゥーリは前より少し育っているかもしれない。

### 2. タネをはじく
- 今日のタネが手元に集まっている（GitHub・HealthKit・Xから自動で見つかったもの）
- 自分で足すこともできる（色を選ぶ、音声・手動メモ、ユジュに話す）
- **タネを上にさっとはじく**と、今日のマスへ飛んで着地し、育って咲く（咲くアニメはこの瞬間だけ）
- 見つかったタネは捨てることも、色を直すこともできる

### 3. 蒔かなかったら
開かなかった日のタネは、日付が変わったらトゥーリが蒔いておく。次に開くと花は咲いていて、トゥーリが得意げにしている。

### 4. 空いた日があったら
- ユジュが **まとめて1回だけ** 聞く：「さいきん なにしてたの？」
  - 何日空いていても質問は1つ。1日ずつは聞かない（質問の列は宿題になる）
  - 聞くのは**アプリを開いたときだけ**。通知では聞かない
- 答えた内容は、空いていた日のうち本人が選んだ日に、**その種類の色で**咲く（選ばなければ直近の空いた日）
  - 休んでいたなら「からだ」の色。ユジュ「げんき いっぱいに じゅうでん してたんだね！」
  - 一律の花にはしない（色＝何があった日か、の約束を守る）
- 「覚えてない」や無回答なら草のまま。何も失わない
- 細かく振り返りたいときは、過去のマスをタップして自分で足せる

### 5. 引いて見る（年の画面）
- 365日の草むら全景と、今年の願いリストが見える
- 願いは年の途中でも足せる。**候補をランダムに1つ提示**してもらうこともできる（気に入れば加える。採用しなくてもよい）
- 願いが叶ったら、その日に特別な花が咲き、年の画面で明るく灯る

## 願いとX

- 願い＝今年1年でやりたいことリスト。目標や宿題ではなく**願いごと**（短冊に近い）
- **Xへの公開は任意**。本人がしたいときだけ。アプリから公開を促さない
- 意味づけは「背水の陣」ではなく**「引き寄せの法則」**：退路を断つためではなく、願いを言葉にして外へ放つ。期限や約束としてではなく「こうなったらいいな」として出す。叶わなくても責められるものは何もない
- 公開したかどうか、反応の数は、庭に一切影響しない
- 公開する中身（願いそのもの／叶った報告／草むらのカード）と見た目は未決定

## 連携

### GitHub
その日にコミット等があればタネ（学習・開発）。件数は見ない。

### HealthKit / Apple Watch
- 運動・睡眠の記録からタネ（からだ）
- Watchからワンタップ/音声でタネを足せる。両手が塞がっていても足せる
- コンプリケーションや簡易庭園表示は第二フェーズ以降。**「まだ蒔いていない」リマインダーは作らない**

### X
- 本人の投稿からタネを見つける。FMで文章から種類を判定
- **リプライ・引用は除外し本人の発信のみ**。対象/除外キーワードはカスタマイズ可能
- 見つかったタネは手元に届くので、蒔くかどうかは本人が決める
- 技術：X API v2（無料枠の制約に注意）。ポーリングは1日数回。OAuth 2.0。連携解除はワンタップ
- 鍵アカウントでも本人のアプリ内でのみ扱う

### 音声・手動メモ
「今日これやった」をサクッと足す。FMが種類を当て、違えば色を直す。

## 夜の振り返りモード（旧案から継続・細部は未検討）

- 寝かしつけ後（21時以降）に最適化。画面を暗めに、音も控えめに
- 今日のタネをはじいて、咲いた花を眺め、ユジュがひとこと言う。それだけの静かな時間

## 画面の役割分担

- **月の画面** … 日々の草と花。タネを飛ばす場所。ユジュとトゥーリがいる
- **年の画面** … 1年の草むら全景と、今年の願い
- **1日の詳細** … マスをタップして、その日にあったことを見る・足す
