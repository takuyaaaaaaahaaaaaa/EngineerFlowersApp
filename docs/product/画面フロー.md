## UX設計の指針

### 「負担にならない」が最優先
ユーザーの1日はすでに育児・仕事・家事で埋まっている。利用が義務にならない設計。

- タネは「水やりを忘れても枯れない」「ログインしなくても自動で育つ」
- 通知は最小限（「花が咲いた」等の嬉しい瞬間に絞る）

### スキマ時間に開ける軽量設計
- **起動から1秒以内に庭が見える**
- 「今日の頑張り」を1タップ記録
- スクロール不要のメイン画面（縦で30日が一画面に収まる）

### 自動化と手動のバランス
- 基本は自動でタネが植わる（GitHub・X・HealthKit）
- 「今日これやった」は音声/手動メモでサクッと追加
- 花の量は自己申告させない。アプリが行動候補と点を仮置きし、ユーザーは削除・カテゴリ修正・追加・ハイライト選択だけ行う
- 自動化されすぎないことで**自分で植える喜び**も残す（咲くアニメの即時ごほうびと接続）

### 夜の振り返りモード
- 寝かしつけ後（21時以降）に最適化。画面を暗めに、音も控えめに
- 「今日の庭を振り返る」専用ビュー（今日見つけた行動候補／成長した紫陽花／残したいハイライト／ユジュからのねぎらい）
- 一日の終わりに自分を肯定できる体験。時間帯で変わる庭の空とも接続
- 自動で植わったぶんの咲くアニメは、初回表示 or この夜モードでまとめて1回再生

## AppleWatch 連携

- **ワンタップ/音声記録**：Watchから短い「やったこと」を即座に追加。仕事/家事育児/学習開発/運動/趣味交流のクイック選択も用意。両手が塞がっていても記録可能
- **HealthKit連携**：ワークアウト終了を検知して運動タネを自動。歩数・スタンド時間と連動。「アクティビティリングを閉じた日」は水やりボーナス
- **コンプリケーション**：文字盤に今日のタネ数 or 直近の花。タップで起動。「今日まだ植えていない」優しいリマインダー
- **簡易庭園表示**：Watch画面に庭の縮小版。新しい花が咲いたときのハプティック通知

## X（旧Twitter）連携

### 基本コンセプト
Xはエンジニアの日常的な「つぶやきアウトプット」の場。ブログを書くまでもない学びや頑張りを拾い、
自動でタネに変えて「気づいたら庭が育っていた」体験を提供。

### 投稿の自動タネ化
- 連携アカウントの投稿を解析して行動候補に変換。ハッシュタグ/キーワード or FMで種類を自動判定
  - `#今日の積み上げ` `#駆け出しエンジニア` → 学習開発／`#育児` `#家事` → 家事育児／`#ランニング` `#筋トレ` → 運動／`#iOSDC` → 趣味交流 or 学習開発
- 写真付き投稿は思い出候補。**リプライ・引用は除外し本人の発信のみ**。対象/除外キーワードはカスタマイズ可能
- 反映前に「今日見つけたこと」に並べ、ユーザーは削除・カテゴリ修正・ハイライト選択だけできる。点数の直接編集はしない

### 反応に応じた成長ブースト
- いいね/リポスト/ブックマーク数でタネの成長が加速。一定数で訪問生き物が現れる（いいね→ハチドリ/チョウ、リポスト→風で花粉、ブックマーク→リスがタネを埋める）
- バズったら特別演出（花火・虹・伝説の花の開花条件にカウント）

### 夢のタネのX公開（背水の陣）
- 年初の夢のタネをXにシェア（「今年はカンファレンス登壇します」等を美しいカード付きで投稿）
- 進捗達成時も自動でシェアカード生成。フォロワーの応援リアクションが庭の水やりに変換
- **「公開 → 応援 → アカウンタビリティのループ」はプロダクトの主要差別化要素**

### Xシェア機能（受動的アウトプット）
- 咲いた花・達成した夢・月間振り返りをワンタップでXに投稿。ヨシタケ風カード自動生成。「#がんばっタネ」でゆるくつながる

### 「Xを見る時間」を「庭を見る時間」に
- TikTok/Xに吸われがちなスキマ時間の受け皿。開くと自分のX投稿が自然にタネになっている小さな喜び
- ユジュが「きょうもXでがんばってたね！」とコメント

### 技術・プライバシー
- X API v2（無料枠の制約に注意、有料も検討）。ポーリングは1日数回。手動で「今のX投稿をタネにする」も用意。OAuth 2.0
- 鍵アカウントでも本人のアプリ内でのみタネ化。どの投稿をタネ化するかの最終判断はユーザー。連携解除はワンタップ

## 「今日のがんばり受信箱」

- **日々の行動を受け取る**：GitHub/HealthKit/X/音声/手動メモから、アプリが「今日見つけたこと」を並べる
- **ユーザー操作**：削除、カテゴリ修正、追加、残したいハイライト選択。点数を直接自己申告するUIは置かない
- **応援メッセージ**：残したい行動には一言メモを付けられる。花の大きさではなく、その日の物語として表示
- **振り返り**：月末や季節の終わりに咲いた紫陽花とともに振り返る

## 「水やり」要素
- 基本は優しいシステム（忘れても枯れない／成長が少し早まる程度のポジティブボーナス）
- 実装案：朝の日課（Watchでも簡単）／水やりで小さな発見／過去のメモがランダム表示／季節イベント（梅雨は自動水やり・冬は雪結晶）／雲から雨エフェクト／一括水やり
- ソーシャル：フレンドの庭に水をあげる（応援）／チームの共同庭園

## コミュニティ要素
- 贈り花機能（友人の頑張りに花のタネをプレゼント、花言葉ギフト、誕生日・記念日の花束、チーム内「今週の頑張りさん」）
- 共同庭園（チーム・家族での共同庭園。それぞれの頑張りが一つの大きな風景を作る）

---

## 「頑張った軌跡」機能（年末向け）
- 日々の音声/手動メモやX投稿のテキストを年末にクラスタリングして「今年あなたは何に時間を注いだか」を見せる
- クラスタごとに「あなたの○○の花畑」、時系列で追える「今年の庭の物語」
- 全自動でユーザーは「見るだけ」。負担ゼロ
- プライバシー：端末内処理を理想とするが重さとのトレードオフは技術選定で要検討

## 全体の画面役割分担
- **カレンダー（庭）** … 日々の花。流れていく日常
- **実った夢の棚（瓶/カゴ）** … 果実。叶えた大きな達成のアーカイブ
- **夜の振り返りモード** … 1日の締めの自己肯定ビュー

## 画面フロー設計（次の設計対象 / 未着手）

UX設計の順序は **ペルソナ → ジャーニーマップ → 画面フロー → コンセプト** の構造化シーケンス。
ジャーニーマップは5フェーズで完成済み（フェーズ③＝習慣形成初期が最高churnリスク、
**③→④の移行＝手動記録から自動連携への遷移が最重要の設計チャレンジ**）。

次の論理ステップが**画面フロー設計**。ここに以下を起こしていく：

- オンボーディング（ユジュのガイド → 最初のタネを植える → 咲くアニメで即時ごほうび）
- メイン庭（縦30日カレンダー、起動1秒以内）
- 1日の詳細（紫陽花の色分解＋根元の行動候補開示、咲くアニメのリプレイ）
- 今日のがんばり受信箱（自動抽出候補／音声・手動追加／削除・カテゴリ修正・ハイライト）
- 夜の振り返りモード
- 実った夢の棚
- 連携設定（GitHub/X/HealthKit/NOLTYインポート）

> 着手時の最重要論点は ③→④ の移行体験。詳細は `引き継ぎサマリ.md` を参照。
