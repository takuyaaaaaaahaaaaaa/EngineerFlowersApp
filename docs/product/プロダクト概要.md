# プロダクト概要 — がんばっタネ / EngineerFlowers

> 「何を・なぜ・誰に」を定義するドキュメント。
> 見た目は `ビジュアルディレクション.md`、頑張り→花の変換は `スコアリングモデル.md`、使われ方は `画面フロー.md` を参照。

## 基本理念

- エンジニアのアウトプットだけでなく、**日々の頑張りも花として表現**する
- ヨシタケシンスケさん風の、温かく少し不思議で親しみやすい世界観
- メッセージ性：「あなたの日々の日常はいつだって素敵で、そしてエンジニアとして花が開きますように」という祈り
- **現実の地味な頑張り（皿洗い・深夜のコミット）が、発光する美しい花に変換される＝アプリ最大の優しさ**

## ターゲットとペルソナ

ターゲットは**家庭を持つエンジニア**。設計判断はすべてこのペルソナの実生活に接地させる。

### ペルソナ：開発者本人

- **職業**：iOSアプリエンジニア（フルタイム・フレックス、9:00始業/18:00終業）
- **家族**：既婚、4歳の娘、2歳の息子 ※マスコットの原型
- **技術**：Swift/SwiftUI、ClaudeCode等のAI活用に興味、VisionPro/EmbedSwiftも関心
- **コミュニティ**：iOSDCスタッフ（「楽しいから参加」に近い）

### 生活と制約

- 毎日、家事・育児（送り迎え・食事・病院）に追われる。自由時間は月1〜2回
- スキマ時間はTikTokに吸われがち。技術キャッチアップはXのみ
- GitHubコミットは波があり空白期間も多い。ブログは月1回、深夜に会社の開発ブログへ
- やりたいことリスト100を4月からNOLTYで管理中

### 頑張りの瞬間（＝花になるもの）

洗濯物を畳む・皿洗い・布団干し／21時までの寝かしつけ・ワンオペ突破／外遊び・送り迎え・勉強の伴走／
筋トレ・ランニング／開発ブログ・個人開発リリース／iOSDCスタッフ参加。

### モチベーションの源泉

数値的な達成感／他者からの承認・応援／**「背水の陣」（公開してやらざるを得ない状況を作る）**／
好きなゲームはゼルダ・ポケモン・牧場物語（育成・コレクション・探索が好き）。

### アプリへの期待

自動でタネが植わる（Watch/X連携）／負担にならない優しいUX／些細な頑張りも認める／でも背中も押す／
夢のタネを公開して背水の陣／達成時のビジュアルフィードバック／可愛くて面白い世界観／子に似たキャラが登場。

### 主要な使用シーン

スキマ時間に常にチェック／ランニング後にWatchからワンタップ／寝かしつけ後に今日の頑張りを振り返る／
X投稿が自動でタネに／夢のタネをXで公開して応援してもらう。

## 機能カタログ

各機能の体験・実装詳細は `画面フロー.md` / `ビジュアルディレクション.md` / `スコアリングモデル.md` に分散。ここは全体像。

### コア（庭と花）
- カレンダーのマスに咲くネオンの花。1マス＝1日＝1輪（→ `スコアリングモデル.md`, `ビジュアルディレクション.md`）
- 標準花：**ネオン紫陽花**。複数カテゴリの頑張りが、1つの毬に集まって咲く
- 成長：芽 → 小さな紫陽花 → 普通の紫陽花 → 大きな手まり紫陽花（量で花序数・毬の密度/大きさが育つ）
- コスモス/ダリア等は標準成長段階ではなく、季節テーマ・月間ハイライト・特別演出の候補に退避
- 果実（一回の大きな達成の結実）＝果物型の宝石（→ `ビジュアルディレクション.md`）

### タネの種類
コードタネ（GitHub）／知識タネ（X・GitHub・将来ブログ）／共有タネ（Q&A）／今日のがんばり（仕事・家事育児・学習開発・休息）／
運動タネ（HealthKit）／リリースタネ（App Store/TestFlight/npm検知）／登壇・コミュニティタネ（connpass等）／
**夢のタネ**（年間目標・やりたいことリスト、最大100、達成で果実、NOLTYインポート）。

### 連携・入力
- **GitHub**：コミットを自動タネ化
- **X（旧Twitter）**：投稿を自動タネ化、反応で成長ブースト、夢のタネ公開（背水の陣）（→ `画面フロー.md`）
- **HealthKit / Apple Watch**：運動を自動タネ化、ワンタップ記録（→ `画面フロー.md`）
- **手動/音声メモ**：「今日やったこと」を追加。ユーザーは点数を自己申告せず、抽出結果の削除・カテゴリ修正・追加・ハイライト選択だけ行う

### コレクション
- **「実った夢の棚」**（花の図鑑マトリクスは廃止）。叶えた夢＝果実がガラス瓶/カゴに堆積（→ `ビジュアルディレクション.md`）

### 開発者向け要素（拡張）
- プログラミング言語マスコット（買い切りIAP）：Swift=ツバメ／Python=ヘビ／Rust=カニ 等。常駐・固有交流・固有効果
- 言語検出でマスコット出現率変化／デバッグコミットで「バグとり虫」／リリース時に花火／深夜コミットでコーヒー型の花 等

### コミュニティ（拡張）
- 贈り花機能（友人の頑張りに花のタネをプレゼント、花言葉ギフト、花束）
- 共同庭園（チーム・家族で一つの風景を作る）

## 課金モデル（ハイブリッド）

1. **基本アプリ：無料** … 庭機能、GitHub/X/音声・手動メモ、今日のがんばり受信箱、控えめバナー広告、夢のタネ（基本版）
2. **プレミアム：一括 1,200円程度** … 広告削除／追加レイアウト／特殊水やり／キャラ追加会話・アニメ／夢のタネ拡張(100個超)
3. **言語マスコット：買い切りIAP** … 個別120〜240円、全言語パック980円程度
4. **季節のタネパック：小額IAP 120〜360円程度** … 季節限定の特別なタネや花
5. **サポーター機能：任意金額 120円〜** … 寄付・サポーターバッジ・感謝メッセージ

## 開発フェーズ

### 第一フェーズ：MVP
1. 基本の庭システム（タネ植え・花の成長・季節変化・紺ペンキ庭+ネオン花・縦30日カレンダー・ユジュ/トゥーリ基本実装）
2. アウトプット連携（GitHub基本／X自動タネ化／音声・手動メモ／シンプルな「今日のがんばり受信箱」）
3. UX（起動1秒以内に庭表示／1タップ記録／夜の振り返りモード／基本アニメ）
4. 夢のタネ（ベータ）（やりたいことリスト最大100／達成で果実／NOLTY手動インポート／実った夢の棚=パターン配置）

> 注：ブログ連携は `スコアリングモデル.md` の決定により MVPでは見送り（XをFMで拾えば回収できるため）。

### 第二フェーズ：機能拡張とビジュアル強化
ビジュアル作り込み（絵本フレーム・紺ペンキ質感・正式キャラデザ）／コミュニティ（フレンド・水やり・共有）／
折りたたみ見開き・Watch・HealthKit／ゲーム性（レア花・訪問動物・言語マスコット・数値的達成演出）／
個人開発・登壇者向け（リリース検知・登壇記録・iOSDC特別タネ）／夢のタネ拡張（自動連携・年末振り返り・X公開・物理演出）／
X連携拡張（成長ブースト・シェアカード・訪問生き物連動）。

### 第三フェーズ：将来
共同庭園・チーム・花言葉ギフト拡充／季節イベント・ストーリー・キャラ成長／Android版・Webアプリ版。

## プラットフォーム / 技術スタック

- iOS（SwiftUI、初期リリース）。**iPhone折りたたみ対応を前提に設計**（縦=30日、見開き=ごほうび）
- AppleWatch対応。将来：Android / Web
- アーキテクチャ：MVVM + Combine／永続化：CoreData／同期：CloudKit（将来）
- API：GitHub, ブログ各種, X API v2, HealthKit, App Store Connect, connpass
- アニメ：SwiftUIネイティブ／達成演出の物理：SpriteKit（演出時のみ）
- 分類：FoundationModel（Apple Intelligence）で文章→行動リスト/カテゴリ/点の仮置き（→ `スコアリングモデル.md`）
