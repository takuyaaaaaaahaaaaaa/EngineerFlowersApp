# がんばっタネ / EngineerFlowers

子育てやプライベートで焦るエンジニアが、開くと自然と落ち着く iOS アプリ。
GitHubの草をオマージュしたカレンダー状の庭に、何もしなくても草が生え、今日あったことは
タネをはじいて飛ばすと**ネオンの花**になる。量は測らない、比べない。

- ターゲット：家庭を持つエンジニア
- 世界観：「あなたの毎日が描き込まれていく絵本」（ヨシタケシンスケ風の温かさ × ネオン）
- 草むらにいる2人：ユジュ（話し相手のお姉ちゃん）／トゥーリ（勝手に育つ弟）
