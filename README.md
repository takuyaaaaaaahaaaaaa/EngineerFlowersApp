# がんばっタネ / EngineerFlowers

エンジニアの日々の頑張り（コーディング・育児・趣味など）を、カレンダー状の庭に咲く
**ネオンの花**として可視化する iOS アプリ。地味な頑張り（皿洗い・深夜のコミット）が、
この世界では発光する美しい花に変換される＝アプリ最大の優しさ。

- ターゲット：家庭を持つエンジニア
- 世界観：「あなたの毎日が描き込まれていく絵本」（ヨシタケシンスケ風の温かさ × ネオン）
- マスコット：ユジュ（花好きの女の子）／トゥーリ（葉っぱ好きの男の子）
